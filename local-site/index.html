    How this runs

    Revit's published model JSON is the raw model input. The processor scans it, recalculates Monroe planning quantities, verifies exports, and writes results to G:\My Drive\SiteBOM. It indexes the four current PDFs and older Monroe files for revision checks. Gemini extraction remains a separate, capped review step.
